# Avito Moderation

## Quick Start

Для запуска необходимы:
- `npm` или иной пакетный менеджер
- бекенд-сервис, запущенный на порту `3001`

> Если бекенд запущен в другом месте, можно заменить путь к нему в [Vite Config](./vite.config.ts) - подставить вместо `http://localhost:3001`

---

### No docker

Перед запуском необходимо скачать зависимости проекта

```bash
npm install
```

После установки - сборка, чтобы было что запускать

```bash
npm run build
```

И можно запускать

```bash
npm run preview
```

В терминале будет показан адрес приложения

---

### Docker 

Собрать изображение

```bash
docker build -t avito-moderation .
```

Запустить compose (запускается только фронтенд, бек ожидается на localhost:3001)

```bash
docker compose up
```

Приложение будет доступно на `localhost:6969`.
---

P.S.

Файл `server.js` предназначен сугубо для проксирования трафика в докере, чтобы избежать CORS ошибки.
